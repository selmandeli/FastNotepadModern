# Fast Notepad Modern (Android Studio Project)

Пълен проект за Android (Kotlin + WebView + Native SAF File Sync Bridge).

## Как да генерирате APK файл:
1. Инсталирайте **Android Studio** (безплатно от developer.android.com/studio).
2. Разархивирайте този ZIP файл.
3. Отворете Android Studio и изберете **Open** -> посочете папката `FastNotepadModern`.
4. Изчакайте Gradle да изтегли зависимостите (около 1-2 минути при първо отваряне).
5. От горното меню изберете **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
6. Когато компилирането приключи, ще се появи известие долу вдясно с линк **locate** — вътре ще намерите готовия файл `app-debug.apk`, който можете да прехвърлите и инсталирате на телефона.
